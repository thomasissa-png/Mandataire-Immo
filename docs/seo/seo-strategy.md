## 0. Synthèse exécutive

ImmoCrew part de zéro : pas de domaine enregistré, pas de contenus indexés, pas de backlinks. Le SEO ne produira pas de trafic les 30 premiers jours. La stratégie est donc construite sur deux vitesses :

- **Quick wins (semaines 1-4)** : fondations techniques irréprochables + ciblage des requêtes longue traîne à faible concurrence
- **Moteur long terme (mois 3-12)** : cocon sémantique blog + landing pages secondaires géolocalisées + link building thématique

L'angle différenciant d'ImmoCrew — marketing pour mandataires indépendants — est peu couvert par la concurrence SEO directe. Cocoon-Immo positionne son blog sur "agence immobilière" (pas "mandataire"). Cette lacune est notre fenêtre d'entrée.

### Sophie (persona principal)

Sophie ne cherche pas "logiciel marketing immobilier". Elle cherche des réponses concrètes à ses problèmes quotidiens. Ses requêtes sont majoritairement informationnelles, formulées comme des questions.

| Problème de Sophie | Requête probable | Type d'intention |
|--------------------|-----------------|-----------------|

| Ses annonces sont génériques | "comment rédiger une annonce immobilière qui attire" / "exemple annonce immobilière originale" | Informationnel |
| Elle n'apparaît pas sur Google | "comment apparaître sur google agent immobilier" / "SEO local mandataire immobilier" | Informationnel + Commercial |

## 4. SEO technique — Audit et recommandations Next.js

### 4.1 État actuel du code (audit réalisé le 2026-03-25)

**Fichiers SEO existants :**
- `src/app/layout.tsx` : metadata de base présente (title, description, OpenGraph). Accentués absents dans les strings (é → e, etc.) — à corriger.
- `src/app/page.tsx` : pas d'export metadata spécifique — utilise les metadata globales du layout.

**Fichiers SEO manquants (à créer) :**
- `src/app/sitemap.ts` : ABSENT
- `src/app/robots.ts` : ABSENT
- Structured data JSON-LD : ABSENT
- Canonical URL : non configurée explicitement

### 4.2 Corrections prioritaires layout.tsx

**Problème détecté :** les accents sont absents dans les metadata (title et description utilisent "equipe", "personnalises", "recois", "EUR" au lieu de "€"). Google indexe ces chaînes — les accents manquants dégradent le rendu dans les SERPs et la cohérence sémantique.

Correction : remplacer les chaînes ASCII par les versions accentuées correctes.

**Title actuel :** `ImmoCrew — L'equipe marketing des mandataires immobiliers`
**Title corrigé :** `ImmoCrew — L'équipe marketing des mandataires immobiliers`

**Description actuelle :** `Chaque mois, recois tes posts, tes articles et tes annonces...`
**Description corrigée :** `Chaque mois, reçois tes posts, tes articles et tes annonces — 100% personnalisés pour ta zone. Tu publies, on fait le reste. À partir de 197€/mois.`

### 4.3 Fichier sitemap.ts à créer

Emplacement : `src/app/sitemap.ts`
Contenu minimum au lancement :
- URL `/` avec changeFrequency `weekly`, priority `1.0`
- URL `/tarifs` avec changeFrequency `monthly`, priority `0.8`
- URL `/blog` avec changeFrequency `daily`, priority `0.7`
- URLs `/blog/[slug]` générées dynamiquement depuis Supabase
- Exclure : `/dashboard`, `/onboarding`, `/admin`

### 4.4 Fichier robots.ts à créer

Emplacement : `src/app/robots.ts`
Règles :
- Allow `/` pour tous les user-agents
- Disallow `/dashboard`, `/onboarding`, `/admin`, `/api`
- Sitemap URL : `https://immocrew.fr/sitemap.xml`

### 4.5 Structured data JSON-LD à implémenter

Schemas prioritaires (détail dans `metadata-templates.md`) :
1. **Organization** — dans layout.tsx (toutes les pages)
2. **Service** — dans page.tsx (landing)
3. **FAQPage** — dans la section FAQ de la landing
4. **Article** — dans les pages de blog ([slug]/page.tsx)
5. **BreadcrumbList** — dans les pages secondaires

### 4.6 Open Graph et Twitter Card

Ajout obligatoire :
- `og:image` : créer une image OG 1200x630 brandée ImmoCrew (bleu nuit + tagline)
- `twitter:card` : `summary_large_image`
- `twitter:site` : compte Twitter/X si créé

### 4.7 Recommandations Core Web Vitals

Basé sur l'architecture Replit + Next.js 14 App Router :

**LCP (Largest Contentful Paint)**
- Image hero : utiliser `next/image` avec `priority={true}` et `sizes` adapté
- Fonts : `display: "swap"` déjà configuré (bien) — s'assurer que les Google Fonts sont chargées en `preload`
- Servir les images en WebP/AVIF

**INP (Interaction to Next Paint)**
- Les Server Components (architecture App Router) limitent le JS client — favorable
- Éviter les Client Components inutiles sur la landing

**CLS (Cumulative Layout Shift)**
- Réserver la hauteur des images avec `width`/`height` explicites dans next/image
- Éviter les polices web sans `font-display: swap` (déjà géré)

## 5. Link building — Stratégie de backlinks

### 5.1 Contexte

Nouveau domaine = autorité zéro. Les backlinks sont le levier le plus lent mais indispensable pour sortir du sandbox Google (typiquement 3-6 mois pour un nouveau domaine sur un secteur concurrentiel).

### 5.2 Sources prioritaires (quick wins — mois 1-2)

**Annuaires et directories thématiques :**
- Annuaire des mandataires immobiliers (si existants — recherche à faire)
- directories de startups / SaaS français : AlternativeTo, Capterra (créer une fiche)
- Product Hunt (lancement officiel à planifier — voir stratégie growth)
- IndieHackers (profil fondateur + post de lancement)

**Presse immobilière :**
- Immo Matin (contact rédaction pour article ou interview)
- Immobilier 2.0 (blog de référence — guest post ou mention)
- MySweetImmo (article de fond sur les mandataires et le digital)

**Groupes et communautés :**
- Les mentions dans les groupes Facebook mandataires génèrent des backlinks indirects (nofollow mais signal social réel)

### 5.3 Stratégie guest post (mois 2-4)

Cibler les blogs à audience mandataires :
- Immo2.pro : proposer un article "5 erreurs marketing que font les mandataires immobiliers"
- Blog des réseaux (si ouvert aux contributions externes) : IAD Academy blog, SAFTI blog
- Blog SeLoger Pro / LeBonCoin Pro : article sur les annonces storytelling

### 5.4 Stratégie partenariats (mois 3-6)

- Coaches et formateurs pour mandataires (ex : "Conseiller Influent", formations ALUR) — échange de visibilité + backlinks mutuels
- Photographes immobiliers : partenariat croisé (ils recommandent ImmoCrew, on les recommande dans les articles)
- Team leaders réseau IAD/SAFTI : article co-signé ou témoignage sur leur blog interne

## 8. Compatibilité SEO / GEO

La stratégie SEO est conçue en complémentarité avec la stratégie GEO (@geo) :

- Les articles de blog servent à la fois le référencement Google et la visibilité dans les LLM (ChatGPT, Perplexity, Claude)
- Les structured data JSON-LD (FAQPage, Article) favorisent les deux canaux
- Les pages locales servent le SEO géolocalisé ET les requêtes d'IA ("meilleur service marketing pour mandataire à Lyon")

Pas de cannibalisation identifiée : SEO cible les moteurs de recherche traditionnels, GEO cible les moteurs génératifs. Les deux channels s'appuient sur le même corpus de contenu.
