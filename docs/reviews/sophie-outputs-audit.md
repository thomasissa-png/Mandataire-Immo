`06 00 00 00 00`, `sophie.martin@iad.fr` (erreur), `{{unsubscribe_url}}` — ImmoCrew a mes vraies coordonnees depuis l'onboarding. Ces placeholders auraient du etre remplis.

### 2. Incoherences geographiques entre livrables
Arret tramway "Confluent" dans les posts vs "place de la Visitation / boulevard Carnot" dans l'article SEO. "Marche place Louis Imbach" dans le calendrier vs "place de la Laiterie" dans tous les autres.

### 3. Manque de guides d'utilisation
Newsletter, landing page, bio Google Business, article SEO — tous ces livrables supposent des actions que je dois savoir faire. Il manque un mode d'emploi en 3 etapes pour chacun.

### 4. Coherence temporelle non verifiee
"5 ans de transactions" dans le LinkedIn, "2024" dans l'article SEO. Le pipeline n'a pas verifie la coherence avec mon profil reel.
