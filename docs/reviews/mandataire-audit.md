## Ce qui me gêne

### 1. Les témoignages sont faux et ça se sent (BLOQUANT)
Marie (IAD Toulouse) et Thomas (SAFTI Bordeaux). Commentaire dans le code : "NE PAS publier tels quels". Un mandataire expérimenté sent immédiatement un témoignage générique. Mettez les métriques et les exemples BeforeAfter à la place. Pas de faux avis.

### 2. "Voir un exemple pour ma zone" — c'est trompeur
Le bouton Hero renvoie vers #pricing, pas vers un exemple. Soit changer le texte en "Voir des exemples concrets", soit pointer vers BeforeAfter.

### 3. Le dashboard vide après paiement est anxiogène
Les stats "Livrables ce mois : 0 / Posts : 0" en gros au-dessus du message d'attente. Quatre zéros = impression d'avoir acheté du vide. Remplacer par : message d'accueil + date estimée + récap commande.

### 4. Les CGV ont des placeholders ouverts (BLOQUANT)
`[NOM DE LA SOCIÉTÉ]`, `[NUMÉRO SIRET]`... Si un mandataire rigoureux lit les CGV, il ferme l'onglet.

### 5. "Personal branding" dans le Pack Lancement
Seul mot de jargon survivant. Remplacer par "Comment te démarquer des autres mandataires de ta zone."

### 6. "Ça t'aide à en vendre dix" — trop ambitieux
"197€/mois. Une vente de plus dans l'année, c'est remboursé — largement." Plus sobre, plus crédible.
